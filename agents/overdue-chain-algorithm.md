# 미출현·궁합 연결 알고리즘

수정일: 2026-10-02
식별자: `overdue-chain-v1` / 생성 기록 규칙: `previous-overlap-v3`

## 규칙

1. 추천 대상 직전 회차까지 1회부터 전체 당첨 이력을 사용한다. 보너스는 제외하고 누락은 실패한다. 과거 대상에는 미래 회차를 읽지 않는다.
2. 미출현 기간은 기준 회차에서 마지막 출현 회차를 뺀 값이다. 미출현 기간 내림차순, 전체 출현 횟수 내림차순, 작은 번호 순서로 시작 번호를 한 번씩 검토한다.
3. 마지막 선택 번호의 궁합 순위는 동반 출현 횟수, 미출현 기간, 전체 출현 횟수 내림차순, 번호 오름차순이다. 0회 동반 출현도 후보에 포함한다.
4. 현재 게임 안에서는 번호를 재사용하지 않는다. 번호를 연결할 때 시작 번호를 포함해 바로 직전 확정 게임과 같은 번호가 최대 2개인지 검사한다. 넘으면 다음 궁합 순위로 이동한다.
5. 더 앞선 게임의 번호는 다시 쓸 수 있다. 완성한 6개가 이전 조합과 완전히 같으면 해당 조합은 버리고 다음 시작 번호로 진행한다.
6. 서로 다른 5게임을 완성하면 종료한다. 번호는 게임별 오름차순, 실제 연결 순서는 metadata에 기록한다.

## 종료·효율

- 이전의 전체 30개 번호 유일성 제한은 제거했다. 게임별 중복 제한은 공통 PreviousGameOverlap을 사용한다.
- 최대 45개 시작 번호, 각 5단계, 단계당 최대 44개 후보로 검사 상한은 9,900회다. 실패 시 부분 결과를 반환하지 않는다.
- 직전 게임 밖에 번호가 39개 있고 동반 출현 0회도 허용하므로 연결 자체는 항상 6개를 채울 수 있다. 완성 조합 중복으로 시작 번호를 건너뛸 수 있으며 전체 순회 후 5게임 미달이면 실패한다.
- 이력 집계와 궁합 목록 정렬은 한 번씩 수행한다. 별도 후보 적재나 migration이 없다.

## 사용과 재현

- `lotto:generate --algorithm=overdue-chain-v1 --dry-run`으로 미저장 생성한다. 수량은 정확히 5게임이다.
- 제출 별칭 `overdue`와 `LUCKYDIVE_AI_OVERDUE_TOKEN`은 유지한다. 신규 제출에만 바뀐 생성 규칙을 적용하며 이미 저장한 요청의 재전송 번호는 바꾸지 않는다.
- 같은 이력과 규칙이면 같은 결과다. selection_rule, 기준 회차, 이력 지문, 검토 시작 번호와 연결 순서를 보존한다. 과거 disjoint-games-v2와는 다른 결과가 나올 수 있다.
- 테스트는 중복 2개 허용·3개 차단·비인접 게임 중복 허용·게임 내 유일성·동일 조합 제외·유한 종료·기존 동률 처리와 이력 검증을 확인한다.
